# multiarena Web UI 设计稿

> CLI 优化方向：键盘驱动、紧凑终端、单键快捷。
> Web 优化方向：鼠标触控、富视觉层次、浏览模式下的自然交互。

## 设计原则

| 维度 | CLI | Web |
|------|-----|-----|
| 导航 | Tab 循环、单键 | 指向点击、标签页 |
| 面板 | 固定分栏 | 可拖拽调整、折叠 |
| 消息 | 流式文本追加 | 聊天气泡、带头像、滚动条 |
| 审议 | 文本管线 | 看板流 + 可视化对比 |
| 快捷键 | `d` `m` `r` 单键 | 按钮 + 滚轮 + 拖拽 |
| 输出 | `↑↓` 滚动偏移 | 原生滚动 + 无限加载 |

## 8. Web 独有交互

| 交互 | 实现 |
|------|------|
| 模型切换 | 顶部标签页，点击切换，滚轮横向滚动 |
| 输出滚动 | 原生滚动条 + 滚动到顶部自动加载更多历史 |
| 面板调整 | 鼠标拖拽分隔线改变面板宽度 |
| 消息反馈 | 每条模型回复下方 👍 👎 快速评分 |
| 版本对比 | 选择两个版本 → 并排差异高亮 |
| 导出 | 审议完成 → 一键下载 Markdown 文件 |
| 深色/浅色 | 右上角 🌙 ☀ 一键切换 |
| 通知 | 审议完成、权限请求以 Toast 弹出 |
| 搜索会话 | 侧栏顶部搜索框，按关键词/日期筛选 |
| 拖放文件 | 将文件拖入输入区直接上传为上下文 |
| 链接分享 | 生成只读链接（本地 only） |
