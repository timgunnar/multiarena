# multiarena Web UI 设计稿

> **实时通信**：Web 前端通过 WebSocket（`ws://`）与服务端通信，实现流式输出、实时推送和双向交互。无轮询、无 SSE。
>
> **CLI** = 程序员工具：键盘驱动、Tab 切换、配置文件、单键快捷。
> **Web** = 小白用户入口：任务导向、点击操作、设置向导、零门槛。

## 配色方案（面向小白的温暖色调）

```
 背景          #fafbfc (浅灰白)
 卡片          #ffffff
 主文字        #1a1a2e
 次要文字      #6b7280
 品牌色        #7c3aed (紫色 — 创意工具感)
 完成/通过     #10b981 (翠绿)
 进行中        #f59e0b (琥珀)
 用户输入      #7c3aed (紫色边框)
 模型回答      #f3f4f6 (浅灰卡片)
 按钮主色      #7c3aed
 悬停效果      #6d28d9
```

**为什么不用深色主题？** 小白用户更习惯白底界面（Google Docs、Notion、飞书），深色终端有距离感。

## Web 独有交互

| 交互 | 说明 |
|------|------|
| 设置向导 | 首次使用时引导配置 API Key，可选"跳过" |
| 任务卡片 | 首页模板化入口，降低选择压力 |
| 自然语言输入 | 不需要 `/team` `/merge` 命令，直接说"帮我写" |
| 进度管 | 审议进度可视化，替代文字轮次描述 |
| 差异对比 | 修改历史用箭头直连原文和修改后文本 |
| 一键操作 | 复制、下载、换风格重写 |
| 口语化配置 | "温和/中等/深度"替代 off/low/medium/high |
| 昵称系统 | 给模型取名，降低技术感 |
| 最近工作 | 首页展示历史，快速继续 |
| 数据管理 | 可视化存储占用，一键导出/清除 |
| 深色/浅色 | 默认浅色，可切换深色 |
